# 智能手表 (Smart Watch) 基于 STM32F103C8T6

## 项目简介
基于江协科技套件开发的智能手表，使用标准库编写，采用面包板搭建，实现时间显示、设置、秒表、姿态检测、电池电压监测等功能。

## 硬件清单
- 主控：STM32F103C8T6 最小系统板
- 显示：0.96寸 OLED (I2C 4针)
- 姿态：MPU6050 六轴传感器 (I2C)
- 交互：EC11 旋转编码器 + 独立按键
- 存储：W25Q64 Flash (SPI)
- 供电：USB 供电（预留锂电池和 TP4056 接口）

## 功能列表
- [x] RTC 时间、日期显示与设置
- [x] 电池电量 ADC 检测（电位器模拟）
- [x] 秒表计时
- [x] MPU6050 姿态数值与图形化水平仪
- [x] W25Q64 掉电保存时间
- [ ] 计步算法（开发中）
- [ ] 蜂鸣器闹钟（开发中）

## 软件架构
- 纯裸机开发，主循环 + 状态机 (page、edit_flag)
- 包含差异刷新和显存机制（OLED_GRAM）
- 一阶低通滤波 + 零偏校准处理 MPU6050 数据
- 4状态正交解码处理 EC11 编码器
- 软件 I2C 和软件 SPI

## 如何使用
1. 使用 Keil MDK5 打开 `Project.uvprojx`。
2. 编译并下载到 STM32F103C8T6。
3. 上电保持水平静止进行 MPU6050 零偏校准。
4. 旋转编码器切换页面，按下确认键进入设置。
