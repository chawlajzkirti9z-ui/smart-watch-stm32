# 智能手表 (Smart Watch) 基于 STM32F103C8T6

## 项目简介
基于江协科技套件开发的智能手表，使用标准外设库编写，面包板搭建。实现了时间显示、日期设置、秒表、姿态检测、倒计时、时间闹钟、息屏、亮度调节、断电保存等功能。菜单式 UI，通过 EC11 旋转编码器和两个独立按键完成交互。

## 硬件清单
- 主控：STM32F103C8T6 最小系统板
- 显示：0.96寸 OLED（I2C 4针，PB8/PB9）
- 姿态：MPU6050 六轴传感器（I2C，与 OLED 共总线）
- 交互：EC11 旋转编码器（PA0/PA1）+ 确认键（PA2）+ 返回键（PA3）
- 存储：W25Q64 SPI Flash（PA4~PA7）
- 蜂鸣器：无源蜂鸣器（PB0，TIM3_CH3 PWM 驱动）
- 电量检测：电位器 / 分压电路（PB1，ADC通道9）
- 供电：USB 供电（预留锂电池 + TP4056 接口）

## 软件架构
- 纯裸机开发，主循环 + 状态机（`page` 页面 + `edit_flag` 编辑标志 + `sub_sel` 子菜单）
- OLED 显存机制（`OLED_GRAM[8][128]`）+ 差异刷新，支持画点、画线、画矩形
- 一阶低通滤波 + 零偏校准处理 MPU6050 数据
- 4 状态正交解码处理 EC11 编码器
- 软件 I2C（OLED + MPU6050）、软件 SPI（W25Q64）
- RTC 以 2000-01-01 为基准，通过计数器换算年月日时分秒
- W25Q64 分区存储：扇区0=时间，扇区1=步数

## 交互说明

**主界面：**
- 旋转 → 切换 Menu / Set
- PA2 → 进入选中项

**Menu（功能列表）：**
- Pose：姿态显示
- Clock：时钟菜单（Time / Alarm / Countdown / Stopwatch）
- Empty：未开发占位

**Set（设置菜单）：**
- Date Time：设置日期和时间
- Sleep：息屏时间（0~60秒）
- Bright：屏幕亮度（0~255）

**通用规则：**
- 旋转 = 切换选项 / 修改数值
- PA2 = 确认 / 进入
- PA3 = 返回（秒表例外：第一次清零，第二次返回）

## 如何使用
1. 使用 Keil MDK5 打开 `Project.uvprojx`
2. 编译并下载到 STM32F103C8T6
3. 上电时保持板子水平静止，等待 MPU6050 零偏校准完成
4. 旋转编码器切换选项，按键操作
